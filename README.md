# Python-Programming
Code Storm Challenge

A beginner-friendly Jupyter notebook of Python programming exercises and worked solutions. The challenges use everyday scenarios to practice core Python concepts, from basic arithmetic and strings to loops, exception handling, and classes.

## Topics covered

- Variables, numeric types, arithmetic, and Boolean expressions
- Strings, indexing, slicing, and built-in methods
- Lists, tuples, sets, and dictionaries
- Conditional statements and loops
- Functions, `lambda`, `map`, `filter`, `reduce`, and `zip`
- Exception handling with `try`/`except`
- Object-oriented programming with simple classes
